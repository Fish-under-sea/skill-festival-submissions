## 📝 2. File submission guidelines

Each team directory comes with **4 subfolders** preset. Put each type of work in its designated folder, and name files consistently so they can be identified:

### 1. Preliminary-round PPT

Holds the team's preliminary-round presentation deck.

```
文件名格式：【小组名】-初赛PPT-作品名.pptx
示例：      【瞬忆•智能记忆】-初赛PPT-智能记忆系统.pptx
```

> The template above is a **literal filename convention** — keep it exactly as shown (in Chinese) when naming files.

### 2. Final-round PPT

Holds the team's final-round presentation deck.

```
文件名格式：【小组名】-决赛PPT-作品名.pptx
```

### 3. Video materials

Holds the work's demo video, defense video, and so on.

```
文件名格式：【小组名】-视频-视频类型.mp4
示例：      【缝合怪】-视频-作品演示.mp4
```

> ⚠️ **If a video exceeds 100 MB, do not upload it directly.** Upload it to a cloud drive instead and create `视频链接说明.txt` in that folder with the cloud-drive link, access code, and a description of the video.

### 4. Other supplementary materials

Holds any other materials the work needs.

```
文件名格式：【小组名】-补充资料-资料名称.后缀
示例：      【智能花盆】-补充资料-设计说明书.docx
```

## 🚀 3. How to submit

### Option 1: Upload directly on the web (recommended, simplest)

1. Open this GitHub repository link and sign in to your GitHub account
2. Find your team's folder and click into it (for example, click 「瞬忆•智能记忆」)
3. Click the matching subfolder (such as 「初赛PPT」), then click **Add file → Upload files** in the top right
4. Drag files into the upload box, or click **choose your files** to pick local files
5. Scroll to the bottom of the page and, under **Commit changes**, write a commit message (for example: `瞬忆•智能记忆 提交初赛PPT`)
6. Choose **Commit directly to the main branch** and click **Commit changes** to finish

### Option 2: Fork + Pull Request (disciplined; for teams comfortable with Git)

1. Click **Fork** in the top right of the repository to copy it to your own GitHub account
2. In your fork, upload and commit files following the guidelines above
3. Click **Compare & pull request**, write a description, and open the merge request
4. Once the administrator approves it, your submission is complete
